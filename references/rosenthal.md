# Rosenthal operational reference

Use the cumulative `rosenthal` library as a contextual editorial source, not as an impersonation and not as a frozen historical norm. Current `russian`/NORM evidence has priority over a source-period prescription.

Canonical routing:

- `libraries/rosenthal/rules-index.json` — cumulative rule groups and counts;
- `libraries/rosenthal/rules.json` — cycle 1;
- `libraries/rosenthal/rules-cycle2.json` — «А как лучше сказать?»;
- `libraries/rosenthal/provenance-cycle2.json` — cycle-2 evidence added to existing rule identities;
- `libraries/rosenthal/model-only.md` — compact contextual residue.

Mechanical findings are emitted by `scripts/lint_rosenthal.py` and must not be duplicated by a model pass. When the Board needs contextual Rosenthal reasoning, load only the relevant rule card / study locator rather than the copyrighted source.
