This matrix classifies all 102 source-study operational rules **before runtime implementation**. Primary-source locators remain in the corresponding `PS-R*` cards; `Locator` below is the stable repository pointer to that card and therefore preserves the source locator transitively without duplicating book-derived prose.

Automation: `M` = `MODEL_ONLY`, `X` = `EXTENDED_SOFT`, `T` = `METRIC_ONLY`. Source-rule `DEFAULT_MECHANICAL = 0`; the later implementation may derive narrower project operators from a rule family.

`+` is a positive detection/application case. `−` is a natural negative control. `B` is a boundary/counterexample. FP risk is for mechanical automation of the **full** source rule.
