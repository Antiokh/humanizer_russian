# legal-document-public-sources

Public normative/methodological source bundle for the legal and official-document layer.

Files:

- `source.md` — source inventory and status;
- `coverage.md` — research coverage;
- `rules.md` — extracted atomic rules;
- `evals.json` — initial own test cases;
- `audit.md` — unresolved source and engineering gaps.

Working runtime reference: `references/legal-document.md`.
