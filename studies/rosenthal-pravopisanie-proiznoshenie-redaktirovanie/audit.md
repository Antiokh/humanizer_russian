## Overgeneralization audit

Rejected transformations:

- `paragraph = topic` as a hard equivalence — one paragraph can contain several supra-sentence units and one unit can be split for emphasis;
- `repeat = bad` — §219 makes repeat a cohesion/rhythm/composition mechanism;
- `parceling = fragment error` — §220 treats parceling as a functional figure;
- `ellipsis = missing words` — §221 treats purposeful omission as a stylistic device;
- `question + answer = AI pattern` — §222 explicitly licenses question/problem structures in educational, scientific and problematic prose;
- `long sentence = bad` — §229 diagnoses competing independent propositions, not character count;
- `shorter = better` — §229 identifies excessive brevity as a source of ambiguity;
- `loanword = bad` — §§142–143 require meaning/register/current usage checks;
- `1999 pronunciation = current norm` — rejected; current dictionaries own present-day pronunciation;
- `punctuation implies logic` — §227 requires checking the underlying relation first;
- `local edit is locally evaluated` — §§230–233 require original/context/whole regression checks.
