# Integration rules

Cycle 5 adds four source-specific contextual rule identities: `ROS-R75`–`ROS-R78`. All are `MODEL_ONLY`.

- `ROS-R75` — semantic/stylistic choice among legitimate punctuation variants.
- `ROS-R76` — coherent authorial punctuation vs ordinary error.
- `ROS-R77` — punctuation of conversational syntax without automatic bookish normalization.
- `ROS-R78` — same-form serial verb semantic unit vs distinct predications.

No spelling list or mandatory punctuation table is copied into a Rosenthal mechanical layer. Current `russian/NORM` is authoritative for concrete contemporary prescriptions.
