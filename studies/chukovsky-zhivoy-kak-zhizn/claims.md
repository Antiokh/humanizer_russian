# Claims audit — «Живой как жизнь»

Status: `INVENTORIED_PENDING_EXTERNAL_AUDIT`.

This file contains claims that must **not** silently become operational rules merely because they occur in the source. External verification is performed only after the independent source inventory/extraction pass.

Statuses initially used here:

- `SOURCE_ONLY` — faithfully recorded from book, no external check yet;
- `HISTORICAL_ONLY` — relevant as source-period history, not current rule;
- `CURRENT_NORM_CANDIDATE` — requires modern authoritative verification;
- `EMPIRICAL_CLAIM` — requires research evidence;
- `VALUE_JUDGMENT` — author's evaluative/moral position, not an empirical rule;
- `PREDICTION` — future-language forecast in source.

## CLM-01 — Language continuously changes

Source locator: `SRC:L468-L488`  
Type: linguistic/general  
Source provenance: `SOURCE_DIRECT` / cited linguistic history

Operational consequence if confirmed: supports R01/R03/R35, but does not identify any particular present-day variant as acceptable.

## Internal consistency findings before external audit

1. The book's strongest anti-slang moral/psychological assertions (CLM-09/10) are weakened by its own explicit counterexamples in the same chapter.
2. The book's defense of expressive redundancy is qualified by its note that the same formula can later become a dead bureaucratic stamp.
3. The book's anti-purism is balanced by a separate defense of normative conservatism; neither half can represent the whole source alone.
4. The book's final prescriptive dictionary is limited *before it begins* by professional and familiar-register exceptions.
5. “Logic does not determine language alone” is not equivalent to “logic is irrelevant”; chapter 10 explicitly restores a role for sense when discussing fresh, non-lexicalized collisions.
