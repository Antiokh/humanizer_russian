# Current-norm audit

Cycle 4 is a 1997 normative/stylistic source. Current Russian norm outranks edition-specific prescriptions. No item below is promoted merely because it appears in Rosenthal.

## Confirmed / preserved

- **Mixed comparative formation (§161):** the source rejects forms such as `более интереснее`. Current Gramota guidance likewise treats double comparative marking as erroneous outside deliberate language play. Existing `ROS-R53` remains narrow; no broader detector is added.
  - https://gramota.ru/spravka/vopros/241290
- **`более старший`:** the source explicitly says the construction does not cause objection. Current Gramota (answer №324406, 31 July 2025) says `более старший возраст` is fully correct. This is an important negative control against overgeneralizing `ROS-R53`.
  - https://gramota.ru/spravka/vopros/324406
- **Duplicate `бы` (§210):** modern Gramota answer №331581 distinguishes incorrect duplication inside one subjunctive subordinate construction from legitimate `бы` in separate predications. `ROS-R54` stays MODEL_ONLY.
  - https://gramota.ru/spravka/vopros/331581

## Changed / narrowed

- **`клипс — клипса` (§144):** the 1997 source labels `клипс` the literary form. Current Gramota explicitly says both singular variants, masculine `клипс` and feminine `клипса`, are correct. The old exclusive preference is therefore marked **OBSOLETE** as a current prescription.
  - https://gramota.ru/poisk?mode=all&query=%D0%BA%D0%BB%D0%B8%D0%BF%D1%81

## Source-period only

- Proper-name and institution capitalization lists (§§11–28), foreign-name transcription (§74), many gender/declension inventories (§§144–175), geographical agreement (§197) and lexeme-specific government inventories (§§198–203) are **SOURCE_PERIOD** until checked item by item against current dictionaries/rules.
- No bulk import of 1997 morphology or capitalization lists into deterministic runtime is permitted.
