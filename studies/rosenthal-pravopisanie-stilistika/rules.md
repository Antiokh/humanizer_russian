# Rule integration

Cycle 4 creates **no new `ROS-R*` identities**. That is intentional.

The source is an older edition in the same lineage as material already integrated in cycles 1 and 3. Its stylistic §§139–213 substantially reproduce mechanisms already represented by the cumulative library. Creating another rule for the same phenomenon would weaken deduplication and make author/source counts misleading.
