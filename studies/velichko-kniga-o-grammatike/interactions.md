# Interaction map — Velichko 2004 fragment

## I01 — Valency cluster
`VEL-R01 + VEL-R15 + VEL-R17` jointly require resolving the lexical-semantic variant before judging case/preposition. `VEL-R16` then checks whether nominalization changed the frame. A repair that only changes the case without checking the predicate can preserve the interference.

## I02 — Event construal cluster
`VEL-R04 + VEL-R08 + VEL-R20` separate process, transition, result and state. The existing Russian `ломаться` state-transition rule is a concrete instance of this broader mechanism. Aspect and voice must not be optimized independently.

## I03 — Subject realization cluster
`VEL-R06 + VEL-R07 + VEL-R09 + VEL-R10 + VEL-R11` show that Russian subjecthood is not synonymous with an overt nominative pronoun. Before inserting a subject, consider indefinite-personal, dative-subject, experiencer and impersonal models.

## I04 — Explicit-subject metric guard
`VEL-M01` is only distributional support for `VEL-R06`; it may trigger a contextual audit but never licenses pronoun deletion by itself.

## I05 — Quantitative agreement
`VEL-R12` is a narrow current-NORM subset. `VEL-R13` and `VEL-R14` are broader semantic agreement choices. Do not generalize the hard quantifier rule to numerals or `X с Y`.

## I06 — Passive perspective and register
`VEL-R18 + VEL-R19 + VEL-R20 + VEL-M02` must be read together: the same situation can be framed as action, result, state, object-centered passive or possessive resultative. Passive density is not an error threshold.

## I07 — Copula semantics and scientific register
`VEL-R05 + VEL-R21 + VEL-R22 + VEL-M03` distinguish zero copula, existential `есть`, bookish `являться`, and essence-description `представлять собой`. Chapter 10's scientific templates are not a generic rewrite target.

## I08 — Participial compression
`VEL-R23 + VEL-R24` are structural/normative guards. Only after they pass may `VEL-R25` compare a relative clause with participial compression. `VEL-R26` checks temporal interpretation so compression does not alter time.

## I09 — Gerund control and exceptions
`VEL-R27` is the central subject-control rule. `VEL-R29` is a current-norm exception for impersonal clauses containing an infinitive with the same semantic subject. `VEL-R28` protects grammaticalized/prepositional forms. `VEL-R30` marks object-infinitive attachment as ambiguous/peripheral.

## I10 — Introductory scope
`VEL-R31 + VEL-R32` require distinguishing parenthetic modality/source from a predicative complement clause. Moving the marker can change which proposition it scopes over.

## I11 — Native idiom preservation
The chapter-3 syntactic phraseologisms are global negative controls for all structure regularizers: formal irregularity and unusual word order are not sufficient evidence of RKI interference.

## I12 — Norm verification boundary
Only `VEL-R12`, `VEL-R23`, `VEL-R24`, `VEL-R27`, `VEL-R29` are promoted as NORM in this cycle, and only after independent current-reference checks. Source pedagogical absolutes in `claims.md` remain below NORM.
