# Counterexamples and preservation controls — Velichko 2004 fragment

These controls prevent RKI diagnostics from turning natural Russian variation into errors. Examples are project-authored.

| Family | Tempting overgeneralization | Preserve / negative control | Why |
|---|---|---|---|
| Explicit subjects | Every overt `они` is learner interference | `Работники уже пришли. Они продают билеты у входа.` | Pronoun has a resolved discourse referent. |
| Indefinite-personal | Russian must always omit actor | `Они позвонили из банка и подтвердили перевод.` | `они` can be an anaphoric or institutional subject. |
| Zero copula | Present-tense `есть` is always foreign | `У нас есть время.` / `Проблема есть, и серьёзная.` | Existential and emphatic `есть` are native. |
| Nominative sentence | `В лесу есть дом` is always wrong | `В этом лесу есть дом, но его не видно с дороги.` | Existential contrast licenses `есть`. |
| Aspect | `невозможно` requires only perfective | `В таком шуме невозможно спать.` | Activity impossibility naturally uses imperfective. |
| Aspect | `не нужно` requires only imperfective | Context-specific perfective and imperfective readings exist | Aspect cannot be a lexical stop-map. |
| Quantifier agreement | Quantitative subject always singular | `Пять студентов выступили с докладами.` | Active individuated actors license plural in many contexts. |
| Joint subject | `X с Y` always plural | `Мать с ребёнком пошла к врачу.` | Instrumental participant can be accompanying, not coordinate. |
| Passive | Passive is un-Russian | `Документ подписан директором.` | Agentive passive is normal in appropriate bookish/official register. |
| Possessive resultative | Replace every `мной + participle` with `у меня` | `Заявление подписано мной лично.` | Agent identity can be informationally central. |
| Stative passive | Every `-ся` passive is a calque | `Дом строится второй год.` | Processual action-passive is normal. |
| `являться` | Ban the verb as bureaucratic | `Это является следствием ошибки` can be appropriate in scientific/legal prose | Register and semantic relation matter. |
| `представлять собой` | Replace it with dash/`это` universally | `Система представляет собой набор взаимосвязанных модулей.` | Essence/structure characterization is a legitimate function. |
| Participles | Replace all `который` clauses with participles | `Дом, в котором мы жили, продали.` | Prepositional relative cannot be compressed mechanically. |
| Participles | Avoid participles as “bookish” | `Данные, собранные вчера, уже проверены.` | Clear participial compression is native and useful. |
| Gerunds | Any impersonal main clause makes gerund wrong | `Проверяя расчёт, можно быстро найти расхождение.` | Modern norm permits impersonal + infinitive with shared semantic subject. |
| Gerunds | `исходя из` obeys ordinary gerund subject control | `Исходя из этих данных, решение выглядит разумным.` | `исходя из` can function as a preposition. |
| Gerunds | Shared subject can be checked by nearest noun | `Открыв дверь, я увидел гостя.` | Control is semantic/syntactic, not nearest-noun matching. |
| Introductory words | Introductory markers are removable filler | `Олег, кажется, согласился.` | Marker changes epistemic stance. |
| Introductory scope | Position is stylistically free | `Олег, кажется, сказал, что приедет.` / `Олег сказал, что, кажется, приедет.` | Position changes scope of uncertainty. |
| Emotion intro | `к радости` needs an explicit possessor | `К радости, поезд пришёл вовремя.` | Current reference usage conflicts with source's stronger learner rule. |
| Syntactic phraseologisms | Irregular syntax is learner error | `Работать так работать.` / `Город как город.` | Productive idiomatic conversational constructions must be preserved. |
