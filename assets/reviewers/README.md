# Reviewer avatars

Editorial-board UIs may show portraits/avatars for reviewer systems.

Do not add a portrait unless its use is legally clear. For every bundled image record source and license in the corresponding reviewer profile (or a future asset manifest).

If a licensed portrait is unavailable, prefer a project-created/stylized avatar instead of copying an arbitrary web image.

An avatar is presentation metadata only. It must not imply that the real author reviewed, endorsed or generated the current recommendation.
