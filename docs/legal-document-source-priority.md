# Source priority

When rules conflict, use this default evidence order within the same applicable jurisdiction and date:

1. applicable current law/normative act;
2. applicable current national standard where it has normative force for the task;
3. official methodological guidance interpreting that source;
4. specialist legal/document-writing scholarship;
5. project-derived heuristic.

This is an evidence priority, not a claim that every ГОСТ provision is legally mandatory for every private document.
