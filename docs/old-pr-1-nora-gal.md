# Старый PR #1 — семантический слой Норы Галь

Исторический источник: PR #1 `Add Nora Gal semantic language checks` в `Antiokh/humanizer--ru`.

Полезная работа из этой ветки теперь входит в `humanizer_russian`, поэтому сливать её в старый форк больше не нужно.

## Что перенесено

Семантический слой сохранён, но больше не привязан к последовательным номерам паттернов, которые могут пересекаться с нумерацией исходного проекта.

Текущие идентификаторы:

- `SEM-ABSTRACT-ALGEBRA` — пустые абстракции, «словесная алгебра»;
- `SEM-VOICE-MISMATCH` — грамматически допустимая речь, неубедительная для данного говорящего или ситуации;
- `SEM-METAPHOR-CONFLICT` — конфликт образных систем, «слова на ножах»;
- `SEM-COLLOCATION` — сломанная или скрещённая сочетаемость, «вывихнутое сочетание»;
- `SEM-SYNTAX-CALQUE` — чужая синтаксическая организация;
- `SEM-FOCUS` — смысловой и информационный фокус.

Действующий справочник: `references/nora-gal.md`.

## Важное изменение архитектуры

Правила Норы Галь — контекстные семантические и редакторские проверки, а не жёсткие запреты и не «истина по регулярному выражению».

Новая иерархия сначала защищает:

1. `SEMANTICS` — не придумывать факты и не менять степень уверенности;
2. `NORM` — не создавать настоящих ошибок русского языка;
3. `NATIVE_USAGE` — выбирать естественный русский среди допустимых вариантов;
4. редакторские рекомендации Норы Галь.

Так семантическая редактура не может улучшать стиль ценой выдуманной конкретики или уничтожения намеренного авторского голоса.

## Что сохранено из ревью

Старое ревью CodeRabbit справедливо указало на два риска первой версии:

- семантические проверки могли пропускаться в режимах только с аудитом;
- требование «сделать конкретнее» могло поощрять добавление фактов, которых не было в исходнике.

В самостоятельном проекте это исправлено напрямую:

- сохранение смысла является жёстким инвариантом в `SKILL.md`, `gpt/INSTRUCTIONS.md` и `docs/semantic-preservation.md`;
- рекомендации Норы Галь прямо запрещают придумывать отсутствующую конкретику;
- `evals/nora-gal.json` проверяет сохранение смысла, а не совпадение с единственным эталонным вариантом.

## Перенесённые проверки

`evals/nora-gal.json` содержит шесть семантических сценариев:

- абстракция без выдумывания деталей;
- несовпадение голоса;
- конфликт метафор;
- нарушенная сочетаемость;
- калька чужого синтаксиса;
- сохранение смыслового фокуса.

Ручные проверки также включены в `gpt/TESTS.md`.

## Почему старый PR закрыт без слияния

Старый PR был построен поверх форка, архитектура которого ещё считала многие корреляции с детекторами языковыми правилами. Теперь семантический слой является частью более широкой самостоятельной архитектуры `Antiokh/humanizer_russian`.

Закрытие старого PR сохраняет обсуждение и историю, но не вносит случайных изменений в `humanizer--ru/main`.
