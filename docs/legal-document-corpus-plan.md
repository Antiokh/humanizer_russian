# Corpus plan

For future evals, build own synthetic/minimal corpus rather than copying source examples:

- service letters: request, response, notification, refusal;
- orders: one executor, multiple executors, deadlines, control clause;
- instructions/policies: scope, terms, duties, exceptions;
- contracts: defined parties, cross-references, appendices, deadlines;
- procedural documents: facts, grounds, request, attachments;
- legislation-like texts: preamble, articles, internal references.

Each case needs PASS/REVIEW/HARD_GATE variants and preservation cases.
