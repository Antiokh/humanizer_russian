# Проверка конфигурации

Перед изменением параметров сохраните текущий файл и убедитесь, что сервис запускается с прежними значениями.

## Порядок

1. Откройте файл конфигурации.
2. Измените только нужный параметр.
3. Запустите проверку.

Команда ниже приведена как код и не должна анализироваться как русская проза:

```bash
python3 scripts/check.py --json text.md
```

В тексте можно сослаться на [документацию проекта](https://example.com/docs) и использовать `config_path` как имя параметра. После проверки сравните результат с исходным состоянием.
