# Serbian sibling scaffold

This directory is the first implementation seed for a Serbian-language sibling project.

Current scope:

- script-aware normalization for Serbian Cyrillic and Latin;
- document-level AI-style signals that require repetition, not one-off lexical bans;
- seed evaluations with explicit anti-rules;
- public-source provenance documented under `docs/serbian_public_sources.md`.

This module is intentionally isolated from the Russian production path until its rule contract and tests are aligned with the main engine.
