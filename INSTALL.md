# Установка humanizer-russian как Agent Skill

`humanizer_russian` упаковывается как каталог Agent Skills с именем `humanizer-russian` и файлом `SKILL.md` в корне. Не собирайте рабочую установку копированием нескольких отдельных файлов: текущий рабочий контур зависит от манифестов библиотек, профилей рецензентов, правил и специализированных линтеров источников.

## Сборка переносимого пакета

Из корня репозитория:

```bash
python3 scripts/package_skill.py --output dist/humanizer-russian.zip
```

Упаковщик использует `skill-package.json` как белый список. ZIP содержит один верхнеуровневый каталог `humanizer-russian/` и внутренний `_package/manifest.json` с SHA-256 и размером каждого файла в байтах.

Для одного и того же состояния репозитория сборка детерминирована: CI собирает архив дважды и требует полного побайтового совпадения.

## Проверка без установки

```bash
python3 scripts/install_skill.py \
  dist/humanizer-russian.zip \
  --dest-root /tmp/unused \
  --inspect
```

Проверка валидирует пути внутри архива, имя `SKILL.md`, состав пакета и контрольные суммы, не создавая каталог навыка.

## Установка в локальный каталог навыков

```bash
python3 scripts/install_skill.py \
  dist/humanizer-russian.zip \
  --dest-root ~/.local/share/agent-skills
```

Будет создан каталог:

```text
~/.local/share/agent-skills/humanizer-russian/
```

Корневой каталог назначения задаётся явно, потому что разные клиенты Agent Skills используют разные места для обнаружения навыков. Передайте в `--dest-root` каталог навыков вашего клиента.

Существующая установка по умолчанию не перезаписывается. Чтобы заменить уже установленный каталог после проверки нового пакета:

```bash
python3 scripts/install_skill.py \
  dist/humanizer-russian.zip \
  --dest-root ~/.local/share/agent-skills \
  --force
```

## Загрузка в продукт с поддержкой Agent Skills

В продукты, поддерживающие загрузку Agent Skills, можно передать `dist/humanizer-russian.zip` напрямую. Пакет использует переносимую структуру каталогов Agent Skills и не зависит от проприетарного расширения `.skill`.

## Что входит в рабочий пакет

Устанавливаемый пакет содержит рабочие инструкции, код компактного режима и редколлегии, включённые библиотеки знаний, профили рецензентов, стили, рабочие справочные материалы, профили и схемы, а также манифесты источников дополнительных данных.

Материалы только для разработки намеренно исключены, в том числе:

- рабочие процессы `.github/`;
- регрессионные примеры `tests/`;
- исследования источников `studies/`;
- наборы модельных проверок `evals/`;
- материалы настройки Custom GPT в `gpt/`;
- скрипты сравнительных прогонов, валидации и модельных проверок, используемые только разработчиками.

Исключения перечислены в `skill-package.json` и проверяются CI после чистой установки.

## Функции, существующие только как проект

Проекты источников дополнительных данных, которые ещё не реализованы, попадают в пакет только как манифесты со статусом `PROJECT`, чтобы план развития оставался видимым. Включить их нельзя. Например, явный запрос:

```bash
printf '%s' 'Тест.' | python3 scripts/review.py \
  --evidence normative_reference \
  --format json
```

должен завершиться ошибкой, пока источник не реализован, не проверен и явно не переведён в статус `OPERATIONAL`.

## Быстрая проверка установленной копии

Выполняйте команды из установленного каталога `humanizer-russian`:

```bash
printf '%s' 'Командой осуществляется проведение проверки.' \
  | python3 scripts/check.py --json

printf '%s' 'Это ошибка не в расчёте, а в исходных данных.' \
  | python3 scripts/review.py --format json
```

CI запускает эти команды из свежей временной установки, а не из исходного каталога, где пакет был собран.

## Проверка спецификации

Чистая установленная копия дополнительно проверяется эталонным валидатором Agent Skills `skills-ref`, закреплённым на известном upstream-коммите. Это независимо от собственных тестов упаковщика ловит расхождения в front matter, имени навыка и структуре каталогов.
